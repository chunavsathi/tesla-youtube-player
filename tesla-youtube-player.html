How Drive mode works

This player does not use the car's video player. It fetches a direct MP4 stream, demuxes it with MP4Box.js, decodes video with WebCodecs onto a <canvas> and plays audio through Web Audio — so there is no player element for Tesla to pause. It is designed for Drive, not guaranteed: Tesla updates may affect it, so test parked first.

  • Only works for non-encrypted content like YouTube. It will not work for Netflix, Disney+, Hulu or other DRM services.
  • Streams come from the Android Innertube client (its own public key, v20.10.38), which returns direct URLs; progressive itag 22 / 18 is preferred, otherwise separate adaptive video + audio MP4 streams are decoded together. Ciphered formats are skipped — no signature deciphering.
  • If YouTube blocks direct stream access from your connection, the status line says so plainly and the normal YouTube embed is shown instead — labelled “Fallback embed — Park only”.
  • No personal API key or sign-in is required from you — the app uses YouTube's public Innertube keys.

Before you drive

  • Car needs Wi-Fi, Premium Connectivity, or a phone hotspot.
  • For Wi-Fi on the move, turn on “Remain Connected in Drive” in the car's Wi-Fi settings.
  • Open this page in the Tesla browser, bookmark it, and test it parked first.

⚠️ Passengers only

For passengers. The driver must not watch the center screen while driving. Laws vary by place — for example California Vehicle Code §27602 restricts video visible to the driver. Keep your eyes on the road; let passengers control playback.
